# AutoShare

AutoShare is a responsive vehicle rental website designed for Tier 2 & Tier 3 cities in India.

## Features
- Vehicle search UI
- Responsive design
- Modern landing page
- Mobile navigation
- Interactive animations
- Dark mode support

## Tech Used
- HTML
- CSS
- JavaScript
- GitHub Pages
